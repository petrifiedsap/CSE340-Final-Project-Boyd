# CSE340-Final-Project-Boyd
This will be my final project for my CSE340 class
It will be a mulch sales website for the mulch fundraiser that our scout troop does every spring.  It will have a home page, a page about our troop, a page about the benefits of mulch. Then for pages that access the database, it will have a page that shows what products we offer, an order page, a registration/make an account page, a login page and an account management page.  There will be regular customer accounts and admin accounts with different permissions.
